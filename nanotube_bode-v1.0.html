Membrane nanotube — input impedance Z(ω)

Distributed (Rall) passive cable in a large, grounded, isopotential bath. The lumen sets the axial resistance r_i; the wall is R_m ∥ C_m. In a true bath the return current is 3-D, so there is no distributed r_e — the bath conductivity enters only as a lumped series access (spreading) resistance R_access ≈ ln(1+2ℓ/a)/(2πσ_o·ℓ), added in series with the cable. Conductivities via σ = c · (1.5 S·m⁻¹ / 155 mM) (PBS-equivalent).

Model & equations
y_m(ω)=1/r_m + jωc_m   γ=√(r_i·y_m)   Z₀=√(r_i/y_m)=R∞/√(1+jωτ)
Z_in(ω) = Z_cable(ω) + R_access ; Z_cable = Z₀·coth(γℓ) [sealed], Z₀·tanh(γℓ) [killed], Z₀ [semi-∞]
R_access ≈ ln(1+2ℓ/a)/(2πσ_o·ℓ) — grounded-bath spreading resistance (thin-cylinder estimate)
Vesicle end (sphere R): Z_L = 1/[4πR²(1/R_m+jωC_m)] + 1/(4πσ_oR) — membrane R∥C in series with sphere→bath spreading; Z_cable = Z₀(Z_L+Z₀·tanh γℓ)/(Z₀+Z_L·tanh γℓ). R→0 ⇒ sealed, R→∞ ⇒ killed.
Per-unit-length (lumen radius a=d/2, perimeter p=πd): r_i=ρ_i/(πa²), r_m=R_m/p, c_m=C_m·p, ρ=1/σ, τ=R_mC_m, λ=√(r_m/r_i), R∞=√(r_m·r_i). Isopotential bath ⇒ no distributed r_e; σ_o acts only through the lumped series R_access. Because the lumen impedance is GΩ–TΩ while R_access is kΩ–MΩ, bath conductivity is negligible except at very high f or for short/wide tubes. Quasi-static; treat f ≳ 1 MHz and d ≲ 5 nm as outside continuum validity.
